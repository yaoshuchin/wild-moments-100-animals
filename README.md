# 此刻野境 WILD MOMENTS · 100 種世界動物觀察站

本專案依據 [statuesque-quokka-f04a88.netlify.app](https://statuesque-quokka-f04a88.netlify.app/) 1:1 復刻打造，並完整擴充為 **100 種全球真實動物生態觀察點**。

## 🌟 快速啟動方式

* **方式一（Windows 一鍵啟動）**：
  直接雙擊目錄下的 start.bat，系統將自動啟動本地伺服器並在瀏覽器中打開 http://localhost:3000。
* **方式二（終端機啟動）**：
  `ash
  node server.js
  `
  打開瀏覽器訪問：http://localhost:3000

## 🧭 核心特色與功能

1. **100 種世界野生動物生態資料庫**：
   - 遍布七大洲與各大洋，包含哺乳類、鳥類、海洋生物、野生動物與爬蟲兩棲。
   - 每種動物皆配有真實經緯度、IANA 時區、高解析生態介紹與「你知道嗎？」趣味科普卡片。
2. **3D 互動數位地球儀**：
   - 2D Canvas 高性能 3D 擬真地球，繪製 Natural Earth 全球向量海岸陸地。
   - **太陽日夜晨昏陰影（Solar Terminator）**：動態演算全球當前時刻白天與深夜分界線。
   - 100 個動物自訂 Emoji 標記，支援點擊聚焦旋轉、縮放與自動自轉開關。
3. **即時過濾與多維度檢索**：
   - **依日夜探索**：全部、☀ 白天、☾ 夜晚（依當地日出日落太陽仰角動態篩選）。
   - **依分類探索**：全部動物、哺乳類、鳥類、海洋生物、野生動物。
   - **即時搜尋**：支援名稱、地點、物種標籤快速過濾。
4. **觀察日誌與影音視窗**：
   - 當地時間秒級精確跳動、日夜狀態即時判定。
   - 支援 YouTube 播放器與官方來源自動回退機制。
   - 支援「我的最愛」收藏功能（保存於瀏覽器 localStorage）。
5. **完整攝影機來源管理**：
   - 支援新增、編輯、刪除、停用/啟用。
   - 支援 JSON 格式來源匯出與匯入備份。
   - 一鍵還原預設 100 筆來源。
